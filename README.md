## Overview

This portfolio is a fully interactive VS Code environment running in the browser. Instead of a static landing page, visitors navigate a real editor shell — file tree, tabs, Monaco editor, integrated terminal, and an AI copilot — to explore projects, experience, and background. Every interaction is intentional: the interface itself is the work.

## Features

| Feature | Description |
|---|---|
| **VS Code Shell** | Activity bar, sidebar, tabs, editor layout, terminal, and status bar |
| **Monaco Editor** | Syntax-highlighted code viewing for HTML, SVG, TypeScript, Markdown, and JSON |
| **Live Preview** | Portfolio files render visually inside the app |
| **Project Explorer** | Browse work through a file-tree interface |
| **AI Copilot** | Ask questions about projects, skills, experience, and background |
| **Integrated Terminal** | Run commands: `whoami`, `projects`, `skills`, `contact`, `github`, `dino`, `clear` |
| **GitHub Integration** | Live repo metadata, commits, and contribution data |
| **URL Sync** | Open files are shareable via query params |
| **Keyboard Navigation** | Full keyboard shortcut support |

## How to Use

### Navigating the Interface

Open [dwijesh.dev](https://dwijesh.dev) in your browser. The layout mirrors VS Code:

- **Explorer panel** (left sidebar) — click any file to open it in an editor tab
- **Editor tabs** — switch between open files; close when done
- **Editor area** — view source code in Monaco or switch to Live Preview for rendered output
- **AI Copilot** — open the panel and ask anything about my projects, skills, or experience
- **Status bar** (bottom) — shows current file and editor state

### Terminal Commands

Open the terminal with Ctrl+` and run any of the following:

```
PORTFOLIO
  whoami          short bio and background
  skills          list technologies and areas
  projects        project list  |  projects open <name>
  timeline        career & education timeline
  contact         GitHub · LinkedIn · email

SYSTEM
  ls              list workspace files
  open <file>     open file in editor
  cat <file>      alias for open
  architecture    system architecture diagram
  stack           technology stack
  logs            live app log stream
  deploy          simulate CI/CD pipeline
  monitor         live system metrics
  theme [name]    list or apply a color theme
  clear           clear terminal

EXTRAS
  neofetch        system info card
  fortune         random dev wisdom
  sudo            nice try
  donut           3D ASCII rotating donut
  dino            chrome dinosaur game
  matrix          enter the matrix
```

### Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + P` | Quick open |
| `Ctrl + Shift + P` | Command palette |
| `Ctrl + Shift + I` | Toggle AI Copilot |
| `Ctrl + `` ` | Toggle terminal |
| `Ctrl + B` | Toggle sidebar |
| `Ctrl + ,` | Settings |
